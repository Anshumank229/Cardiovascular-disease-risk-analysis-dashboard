# Cardiovascular-disease-risk-analysis-dashboard


This project analyzes cardiovascular disease risk factors using a healthcare dataset from Kaggle. The dataset was cleaned, transformed, and analyzed to identify patterns related to heart disease prevalence.

Project Objective

To analyze patient health data and identify major risk factors contributing to cardiovascular disease.

Tools Used
Power BI
Excel / CSV
Data Cleaning
Data Transformation
Kaggle Dataset
Dataset Information
Source: Kaggle
Records: 309K+ patient records
Features: Age, Gender, BMI, Smoking, Exercise, Alcohol Consumption, Heart Disease Status
Key Insights
Identified high-risk age groups for heart disease
Compared disease rates across gender
Analyzed impact of smoking habits
Studied exercise habits and disease prevalence
Examined alcohol consumption trends
Dashboard Features
KPI cards
Interactive filters
Age analysis
Lifestyle habit analysis
Risk distribution charts
